# Here to Celebrate uptime monitor

Checks the Here to Celebrate health page about every 5 minutes using [Upptime](https://github.com/upptime/upptime) (MIT license) on GitHub Actions. If the site is down, an issue opens here and is assigned to the owner. It closes when the site recovers.

The self-update and status website workflows are switched off on purpose. To change the Upptime version, edit the workflow files by hand.
